# 배뽑디

2Way 배치 & 뽑기 디펜스 모바일 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. GitHub Pages는 저장소 루트의 `index.html`을 배포하면 됩니다.

## 현재 룰

- 왼쪽은 잡몹 라인입니다. 몬스터가 전체 테두리를 빙글빙글 돌며 누적됩니다.
- 왼쪽 중앙 배치칸은 5x4, 총 20칸입니다.
- 오른쪽은 상자/보스 라인입니다. 10라운드 전에는 보물상자 하나만 나오고, 부수면 실버코인을 줍니다.
- 10라운드부터는 상자가 사라지고 보스 하나만 등장합니다.
- 대기석은 10칸입니다.
- 물 유닛은 빔 투사체, 풀 유닛은 초록 구체, 불 유닛은 타격 지점 점화로 공격합니다.
- 판매선택을 누른 뒤 유닛을 계속 터치하면 여러 개를 연속 판매할 수 있습니다.
- 코인은 실버, 골드, 다이아, 보스코인 4종이며 상위 코인은 하위 코인으로 쪼갤 수 있습니다.
