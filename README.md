# 배뽑디

2Way 배치 & 뽑기 디펜스 모바일 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. GitHub Pages는 저장소 루트의 `index.html`을 배포하면 됩니다.

## 현재 룰

- 화면은 왼쪽 잡몹 라인과 오른쪽 상자/보스 라인으로 나뉩니다.
- 왼쪽 잡몹은 전체 테두리를 빙글빙글 돌며 계속 누적됩니다.
- 중앙 슬롯에 배치한 유닛은 투사체를 날려 라인 위 적에게 피해를 줍니다.
- 1라운드부터 오른쪽에는 보물상자가 돌고, 부수면 코인을 줍니다.
- 10라운드부터 보물상자가 사라지고 보스가 등장합니다.
- 1코인으로 유닛을 뽑고, 코인으로 원소 업그레이드를 누르는 압박형 구조입니다.
