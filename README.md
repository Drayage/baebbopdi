# 배뽑디

배치 & 뽑기 디펜스 모바일 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. GitHub Pages에서는 저장소 루트의 `index.html`을 배포 대상으로 쓰면 됩니다.

## 반영된 핵심

- 40칸 전장: 잡몹 라인 20칸, 보스 라인 10칸, 안전 대기석 10칸
- 1 실버코인 = 1뽑
- 아이언부터 전설까지 6단계 직접 뽑기
- 불, 물, 풀 상성 및 원소별 계단식 업그레이드
- 5라운드 보스 속성 예고
- 10, 20, 30라운드 보스와 최종 보스 실드/소환 패턴
- 어픽스 웨이브, Tap-to-Move, DPS 미터, 누적 킬 표시
