# 배뽑디

2Way 배치 & 뽑기 디펜스 모바일 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. GitHub Pages는 저장소 루트의 `index.html`을 배포하면 됩니다.

## 현재 룰

- 전체 30라운드이며 라운드마다 글로벌 속성이 지정됩니다.
- 라운드 속성 비율은 무상성 12개, 불/물/풀 각 6개입니다.
- 불은 풀에 강하고, 풀은 물에 강하고, 물은 불에 강합니다.
- 5라운드부터 10/20/30라운드 보스 속성이 예고됩니다.
- 왼쪽 잡몹 라인은 5x4 총 20칸 배치 영역입니다.
- 잡몹 수가 100마리에 도달하면 즉시 패배합니다.
- 일반 웨이브는 라운드 시작 시 하나의 속성과 하나의 어픽스로 결정됩니다.
- 오른쪽 라인은 긴 지그재그 경로이며 상자와 보스가 천천히 내려옵니다.
- 오른쪽 보스 라인 배치 영역은 10칸입니다.
- 대기석 유닛은 한 번에 왼쪽 라인으로 배치하거나, 대기석 전체를 한 번에 판매할 수 있습니다.
- 10/20/30라운드 보스는 각각 한 번만 등장합니다.
- 30라운드 보스는 잡몹이 살아 있으면 받는 피해가 80% 감소하고 주기적으로 잡몹을 소환합니다.
- 기본 유닛은 특수 능력이 없는 순수 딜러입니다.
- 특수 유닛은 다이아코인으로 별도 구매합니다.
- 판매 보상: 골드 유닛은 실버 1, 실버 유닛은 실버 0.5, 브론즈 유닛은 실버 0.25, 아이언 유닛은 실버 0.125입니다.
- 보스코인은 다이아 픽, 다이아코인은 골드 픽, 골드코인은 실버 픽에 사용할 수 있습니다.
- 유닛 칸에는 랭크 문자 대신 원소 아이콘을 크게 표시하고, 랭크는 작은 배지로 표시합니다.
- DPS 미터는 필드에 배치된 유닛의 현재 상성 반영 DPS를 표시합니다.
